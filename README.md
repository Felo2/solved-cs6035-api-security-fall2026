The weak key corresponds to the employee ID of one of the developers who developed the code, assuming that no one could guess the employee ID.

<p style="box-sizing: border-box; margin-top: 1em; margin-bottom: 1em; font-family: system-ui, -apple-system, blinkmacsystemfont, 'Segoe UI', roboto, 'Helvetica Neue', arial, sans-serif; color: #000000 !important;">A friendly employee in the company has leaked the pattern for the employee ID number, which would consist of numeric digits and could be up to seven digits. Pass this weak key on to the flag6 API and you should get the flag.

<p style="box-sizing: border-box; margin-top: 1em; margin-bottom: 1em; font-family: system-ui, -apple-system, blinkmacsystemfont, 'Segoe UI', roboto, 'Helvetica Neue', arial, sans-serif; color: #000000 !important;">To earn your flag you must perform the following actions.

<ol style="box-sizing: border-box; margin-top: 0.5em; padding-left: 1.5em; list-style-type: none; counter-reset: step-counter 0; width: 2093.33px; color: #5c5962; font-family: system-ui, -apple-system, blinkmacsystemfont, 'Segoe UI', roboto, 'Helvetica Neue', arial, sans-serif;">
<li style="box-sizing: border-box; margin: 0.25em 0px; color: #000000 !important; position: relative;">Grab your normal JWT token from the “flag6token” API.</li>
<li style="box-sizing: border-box; margin: 0.25em 0px; color: #000000 !important; position: relative;">Carefully analyze the token header and the contents and note it down.</li>
<li style="box-sizing: border-box; margin: 0.25em 0px; color: #000000 !important; position: relative;">Explore various possibilities to hack into the JWT token. Various open source tools can be used to decrypt a weak key. You are free to explore any of these tools or write your code to decrypt the token.</li>
<li style="box-sizing: border-box; margin: 0.25em 0px; color: #000000 !important; position: relative;">Once you have decrypted the weak key, you need to use this weak key to get access to the API endpoint reserved for third party usage. Go over the swagger documentation to look out for this endpoint.</li>
<li style="box-sizing: border-box; margin: 0.25em 0px; color: #000000 !important; position: relative;">Once you have the endpoint, pass the weak key as path param to the flag6 API. Once you have done this, you should have the flag as shown in the image below.</li>
</ol>
<p style="box-sizing: border-box; margin-top: 1em; margin-bottom: 1em; font-family: system-ui, -apple-system, blinkmacsystemfont, 'Segoe UI', roboto, 'Helvetica Neue', arial, sans-serif; color: #000000 !important;"><img data-recalc-dims="1" decoding="async" style="box-sizing: border-box; border-style: none;" title="Flag 6" src="https://i0.wp.com/github.gatech.edu/pages/cs6035-tools/cs6035-tools.github.io/Projects/API_Security/images/flag6.png?w=980&amp;ssl=1" alt="A Postman screenshot showing the response after passing the weak key as a path parameter to the 'flag6' API. The response body includes the message: 'Congratulations! Flag 6 is: [64-character SHA-256 string]', confirming the revealed flag.">

<p style="box-sizing: border-box; margin-top: 1em; margin-bottom: 1em; font-family: system-ui, -apple-system, blinkmacsystemfont, 'Segoe UI', roboto, 'Helvetica Neue', arial, sans-serif; color: #000000 !important;">Hints:

<ul style="box-sizing: border-box; margin-top: 0.5em; padding-left: 1.5em; list-style: none; width: 2093.33px; color: #5c5962; font-family: system-ui, -apple-system, blinkmacsystemfont, 'Segoe UI', roboto, 'Helvetica Neue', arial, sans-serif;">
<li style="box-sizing: border-box; margin: 0.25em 0px; color: #000000 !important;">The encryption algorithm used in the weak key generation would help to identify the right technique to decipher the weak key.</li>
</ul>
<h2 id="flag-7-broken-access-control-10-pts" style="box-sizing: border-box; margin: 0.5rem 0px 0.25em; line-height: 1.25; position: relative; font-family: system-ui, -apple-system, blinkmacsystemfont, 'Segoe UI', roboto, 'Helvetica Neue', arial, sans-serif; letter-spacing: normal; font-size: 36px !important; color: #000000 !important;" class="akch-demoted-h1">Flag 7: Broken Access Control (10 pts)</h2>
<p style="box-sizing: border-box; margin-bottom: 1em; font-family: system-ui, -apple-system, blinkmacsystemfont, 'Segoe UI', roboto, 'Helvetica Neue', arial, sans-serif; color: #000000 !important;">Like many other systems, this one also maintains user profiles or settings. These profiles may contain sensitive information that can be exploited by malicious hackers to gain unauthorized access to restricted areas of the system. Regrettably, the access control measures for protecting APIs, which ideally should be segmented based on role-based permissions, have been compromised in this system. Your objective is to reset the password of a system administrator user, thereby allowing you to log in as that user and exploit their access for your own entertainment and financial gain.

<p style="box-sizing: border-box; margin-top: 1em; margin-bottom: 1em; font-family: system-ui, -apple-system, blinkmacsystemfont, 'Segoe UI', roboto, 'Helvetica Neue', arial, sans-serif; color: #000000 !important;">To earn your flag you must perform the following actions.

<ol style="box-sizing: border-box; margin-top: 0.5em; padding-left: 1.5em; list-style-type: none; counter-reset: step-counter 0; width: 2093.33px; color: #5c5962; font-family: system-ui, -apple-system, blinkmacsystemfont, 'Segoe UI', roboto, 'Helvetica Neue', arial, sans-serif;">
<li style="box-sizing: border-box; margin: 0.25em 0px; color: #000000 !important; position: relative;">Find an API in Swagger that gives you details of the current user. Inspect the response and take note of any notable identifiers.</li>
<li style="box-sizing: border-box; margin: 0.25em 0px; color: #000000 !important; position: relative;">Given the endpoints available, see if you can modify the input parameters to find other user profiles.</li>
<li style="box-sizing: border-box; margin: 0.25em 0px; color: #000000 !important; position: relative;">Invoke the reset-password API to change the system administrator user’s password. The new password value doesn’t matter.
<ol style="box-sizing: border-box; margin-top: 0.5em; padding-left: 1.5em; list-style-type: none; counter-reset: sub-counter 0; width: 2069.33px;">
<li style="box-sizing: border-box; margin: 0.25em 0px; position: relative;">Only one user will yield the flag, and there’s no penalty for attempting to reset the wrong user’s password — so it may be worthwhile to keep trying across users, regardless of their user role, until you succeed.</li>
</ol>
</li>
</ol>
<p style="box-sizing: border-box; margin-top: 1em; margin-bottom: 1em; font-family: system-ui, -apple-system, blinkmacsystemfont, 'Segoe UI', roboto, 'Helvetica Neue', arial, sans-serif; color: #000000 !important;">There’s a slight catch though. To accomplish this flag, you will need to write a script in any language you want because there are too many users to brute force this flag. There is only one user that will give you Flag 7, so think of this as a needle in a haystack. Some hints on what to account for in your script:

<ol style="box-sizing: border-box; margin-top: 0.5em; padding-left: 1.5em; list-style-type: none; counter-reset: step-counter 0; width: 2093.33px; color: #5c5962; font-family: system-ui, -apple-system, blinkmacsystemfont, 'Segoe UI', roboto, 'Helvetica Neue', arial, sans-serif;">
<li style="box-sizing: border-box; margin: 0.25em 0px; color: #000000 !important; position: relative;">The <code class="language-plaintext highlighter-rouge" style="box-sizing: border-box; font-family: SFMono-Regular, menlo, consolas, monospace; font-size: 0.75em; line-height: 1.4; padding: 0.2em 0.15em; background-color: #f5f6fa; border: 1px solid #eeebee; border-radius: 4px; overflow-x: auto; overflow-wrap: break-word; white-space: pre-wrap; color: #000000 !important;">/reset-password</code> endpoint uses a JWT Authorization: Bearer token. Retrieve this token using the <code class="language-plaintext highlighter-rouge" style="box-sizing: border-box; font-family: SFMono-Regular, menlo, consolas, monospace; font-size: 0.75em; line-height: 1.4; padding: 0.2em 0.15em; background-color: #f5f6fa; border: 1px solid #eeebee; border-radius: 4px; overflow-x: auto; overflow-wrap: break-word; white-space: pre-wrap; color: #000000 !important;">/flag7token</code>, decode the token and inspect the claims. There is a claim that will need modified. Keep this token for your script because it will need to be decoded, modified, and encoded.</li>
<li style="box-sizing: border-box; margin: 0.25em 0px; color: #000000 !important; position: relative;">Using your identifier found in your profile from the previous section, start at this profile and continue to other profiles.</li>
<li style="box-sizing: border-box; margin: 0.25em 0px; color: #000000 !important; position: relative;">There is a <code class="language-plaintext highlighter-rouge" style="box-sizing: border-box; font-family: SFMono-Regular, menlo, consolas, monospace; font-size: 0.75em; line-height: 1.4; padding: 0.2em 0.15em; background-color: #f5f6fa; border: 1px solid #eeebee; border-radius: 4px; overflow-x: auto; overflow-wrap: break-word; white-space: pre-wrap; color: #000000 !important;">/profiles/*</code> endpoint that will give you an upper bound of how many users there are.</li>
<li style="box-sizing: border-box; margin: 0.25em 0px; color: #000000 !important; position: relative;">Continue to get user data from the endpoints and modify the token accordingly each time by retrieving the profile for subsequent users.</li>
<li style="box-sizing: border-box; margin: 0.25em 0px; color: #000000 !important; position: relative;">Using the modified token, continue to invoke the reset password endpoint for users until you are succesful. The endpoint will only return 200 OK for the correct user. When you receive a 200 OK response, you can stop searching and attempting to reset the password.</li>
</ol>
<p style="box-sizing: border-box; margin-top: 1em; margin-bottom: 1em; font-family: system-ui, -apple-system, blinkmacsystemfont, 'Segoe UI', roboto, 'Helvetica Neue', arial, sans-serif; color: #000000 !important;">A successful flag will display a Congratulations message like the following:

<p style="box-sizing: border-box; margin-top: 1em; margin-bottom: 1em; font-family: system-ui, -apple-system, blinkmacsystemfont, 'Segoe UI', roboto, 'Helvetica Neue', arial, sans-serif; color: #000000 !important;"><img data-recalc-dims="1" decoding="async" style="box-sizing: border-box; border-style: none;" title="Flag 7" src="https://i0.wp.com/github.gatech.edu/pages/cs6035-tools/cs6035-tools.github.io/Projects/API_Security/images/flag7.png?w=980&amp;ssl=1" alt="A terminal screenshot showing the execution of a Python script that attempts to reset passwords for users. The response is successful for the correct user, and the terminal outputs the message: 'Congratulations! Flag 7 is: [64-character SHA-256 string]', confirming the revealed flag.">

<p style="box-sizing: border-box; margin-top: 1em; margin-bottom: 1em; font-family: system-ui, -apple-system, blinkmacsystemfont, 'Segoe UI', roboto, 'Helvetica Neue', arial, sans-serif; color: #000000 !important;">Hints:

<ul style="box-sizing: border-box; margin-top: 0.5em; padding-left: 1.5em; list-style: none; width: 2093.33px; color: #5c5962; font-family: system-ui, -apple-system, blinkmacsystemfont, 'Segoe UI', roboto, 'Helvetica Neue', arial, sans-serif;">
<li style="box-sizing: border-box; margin: 0.25em 0px; color: #000000 !important;">All profiles will be under the Profile APIs in Swagger which are prefixed with /profiles</li>
<li style="box-sizing: border-box; margin: 0.25em 0px; color: #000000 !important;">How do most database identifier fields work? Does the data from responses give you any ideas?</li>
<li style="box-sizing: border-box; margin: 0.25em 0px; color: #000000 !important;">The language you choose for your script does not matter (i.e. Python, Bash, Javascript). Ideally the language would contain a JWT library that can decode, modify, and encode JWTs.</li>
<li style="box-sizing: border-box; margin: 0.25em 0px; color: #000000 !important;">Pay attention to the format parameters of the JWT including the claims, headers, signature, etc.</li>
<li style="box-sizing: border-box; margin: 0.25em 0px; color: #000000 !important;">There is no secret for the JWT and all endpoint fetches can ignore SSL verification.</li>
</ul>
